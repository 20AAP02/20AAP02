## 🚀 What I'm doing now

Building and running **cloud-native, microservice-based systems** at Nokia — writing services in
**Go**, shipping them onto **Kubernetes**, and keeping the delivery pipelines green with **Jenkins**.
Day to day that means containers, CI/CD, observability and the general DevOps side of getting
software from a commit to production.

Before Nokia I went through **42 Lisbon**, where I worked in C and C++ on everything from a
shell and a raycasting engine to an IRC server and a Dockerised full-stack web app.
