# Privacy notice — Cursor Notion finance sync

This application is a personal Open Banking client used only by António Abranches Pinto (`antoniomariabranches@gmail.com`) to read his own Revolut account information and write it into his private Notion finance workspace.

## Data collected
- Account identifiers, balances, and transactions returned by Enable Banking after explicit Revolut consent
- Session identifiers required to refresh that consent

## Use
Data is used solely to keep personal Notion expense and account tables up to date. It is not sold, shared, or used for advertising.

## Storage
API keys and session identifiers are stored as private environment secrets on the operator's machines. Transaction data is stored in the operator's Notion workspace.
